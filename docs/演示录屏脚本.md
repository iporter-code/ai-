## 复现录制

```powershell
# 1. 确保索引是最新的
python -m app.cli ingest

# 2. 运行演示脚本（会真实调用 2 次生成 + 2 次拒答）
powershell -NoProfile -ExecutionPolicy Bypass -File docs\demo.ps1
```

录屏使用 Windows `gdigrab`，裁掉桌面后输出 1920×1080；命令与输出均来自本机真实运行。若使用 Pollinations 免费接口，4 次 LLM 调用之间已留出 30 秒以上间隔，避免 402 限流。

## 注意事项

- 视频不包含 API Key、`.env` 内容或私人文件；`info` 只显示“Key 已配置”。
- 陷阱题已用 `eval/questions.jsonl` 和检索结果确认：语料中没有 Chroma 版本号，也没有莫干山内容。
- Web 界面启动方式：`python -m app.ui`，默认 `http://127.0.0.1:7860`；交互逻辑与 CLI 相同。

# 语料目录说明

`data/raw/` 是本作业使用的个人知识库语料，共 3 个文档、5 781 个字符，覆盖两种格式：

| 文件 | 格式 | 总字符 | 非空白字符 | 纯汉字 | 汉字+英文/数字串 |
| --- | --- | ---: | ---: | ---: | ---: |
| `大模型前沿课程笔记.md` | Markdown | 2 426 | 2 246 | **1 530** | 1 635 |
| `RAG实验日记.md` | Markdown | 1 888 | 1 688 | 1 037 | 1 162 |
| `Python环境配置备忘.txt` | TXT | 1 467 | 1 223 | 354 | 485 |

三份文档都是围绕本课程作业整理的第一人称笔记，其中包含自己的实验数字、判断和踩坑记录。

**字数口径**：作业只写“不少于 1500 字”，没有规定是否排除标点/英文。按 Word 常见的“汉字每字计 1、英文/数字串每串计 1”口径，最长一篇为 **1 635 字**；按纯汉字统计为 **1 530 字**。为避免歧义，本仓库同时给出上表四个口径，统计脚本可复现：`python scripts/count_corpus.py`。如果课程按纯汉字严格统计，最长一篇为 1 530 字，也已超过 1 500 字。

## 索引

`data/index/` 是自动生成物，已加入 `.gitignore`：

- `chunks.json`：按 300 字切分、约 50 字整句重叠得到的 32 个片段；
- `vector/embeddings.npy`：bge-small-zh-v1.5 的 512 维归一化向量；
- `vector/meta.json`：模型名、片段数和指纹；语料变化后会自动重建。

重新构建：

```bash
python -m app.cli ingest
```
